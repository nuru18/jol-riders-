# Riders Bar — собранный сайт

Готовая сборка концепт-редизайна сайта **Riders Bar** — веранды на берегу
Аэропортинского озера (Бишкек, проспект Чынгыза Айтматова, 90/92).
Здесь лежит только результат сборки — исходники в отдельном проекте.

> Концепт-редизайн, неофициально. Данные и фото — из публичной карточки 2ГИС.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**,
папка **/ (root)** → Save.

Важно: **сначала включите Pages, дождитесь строки «Your GitHub Pages site
is currently being built»**, и только потом делайте коммит. Сборка
запускается по пушу — если коммит был раньше включения, публикация
не стартует.

Адрес: https://nuru18.github.io/jol-riders-/

## Три главные вещи

**Режим дня.** Riders открывается в полдень, а не вечером, и одна веранда
живёт тремя жизнями: днём обед и вейкборд, к закату коктейли, ночью кальян
до двух. Сайт определяет текущий режим по часам; ночь тянется за полночь,
поэтому 01:00 считается за 25:00.

**Бронь.** Зоны разного размера: пуфы 2–8, веранда до 12, VIP до 20, банкет
30–200. На 25 гостей готовой зоны нет — форма предлагает позвонить, а не
молчит. Закатный час с 18 до 21 подсвечен: в это время мест просят больше
всего.

**Волна.** Секции разделены кромкой воды, а не линией: две волны едут
навстречу с разной скоростью. Путь шире кадра и периодичен, сдвиг равен
периоду — стык не виден.
